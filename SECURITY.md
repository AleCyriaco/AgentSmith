# Reporting security issues

Do not publish credentials, tokens, private machine addresses, or unredacted screenshots in issues. Use GitHub's private vulnerability reporting when it is enabled on this repository. If it is unavailable, open a minimal issue requesting a private reporting channel without including exploit details or sensitive data.

AgentSmith is a preview. Security fixes are developed against the current branch; there is no guaranteed long-term support window. See [privacy and trust boundaries](docs/privacy.md).
